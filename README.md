# tailwindex

A single-file Tailwind CSS playground for learning and editing classes fast.

- Live preview with click-to-select elements
- Searchable A–Z Index of Tailwind utilities; click a row to add or swap a class
- Changed classes turn orange in the editor
- Right-click menu: export (HTML, JSX, Vue, permalink), send to Claude

Open `index.html` in a browser. It loads Tailwind from a CDN, so it needs a connection.
